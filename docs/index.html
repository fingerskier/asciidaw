A small terminal DAW

Record. Edit.
Get a WAV out.

asciidaw handles the straightforward job: record a track or two, trim your takes, and export a mix. Work with your keyboard or mouse, right in the terminal.

01 / Overview

Just enough DAW

Record mono or stereo input on multiple tracks while hearing the rest of the project. Edit clips, set gain and pan, then export a stereo or mono mix, stems, or one clip as WAV.

Capture

Arm tracks, choose input channels, watch live meters, and record takes into your project.

Arrange

Split, cut, paste, duplicate, nudge, drag, fade, normalize, and undo clip edits.

Mix

Mute or solo tracks, set track gain and pan, and export 16, 24, or 32-bit float WAV.

Automate

Use headless record, export, and info commands without the interface.

02 / Install

Choose a build

Download a prebuilt Linux or macOS binary from Releases. Set target to one of x86_64-unknown-linux-gnu, aarch64-unknown-linux-gnu, aarch64-apple-darwin, or x86_64-apple-darwin.

target=x86_64-unknown-linux-gnu
mkdir -p ~/.local/bin
curl -fsSL "https://github.com/fingerskier/asciidaw/releases/latest/download/asciidaw-$target.tar.gz" \
  | tar -xz -C ~/.local/bin asciidaw
asciidaw --version

For a source build, install Rust 1.88 or newer. Linux also needs ALSA development headers and pkg-config. Then run:

cargo install --locked --git https://github.com/fingerskier/asciidaw

Linux is the tested platform. Linux binaries need glibc 2.35 or newer and libasound.so.2. macOS builds are unsigned; Windows is not supported yet. ffmpeg is optional and only needed to import non-WAV files.

03 / Quick start

From input to mix

asciidaw devices                     # list available audio devices
asciidaw my-song                     # open or create a project
asciidaw my-song --input "Scarlett"  # choose a device by name or ID
  1. Choose a track and its input channel. Press a to arm it.
  2. Press r to record. Press space or r to stop.
  3. Move the cursor, edit the take, and press e to export a mix into exports/.

For recording or exporting without the interface:

asciidaw record take.wav -c 1-2 -d 3:00
asciidaw export my-song --stems -b 16
asciidaw info take.wav

04 / Editing

Keyboard and mouse

KeyAction
space / enterPlay or stop; Enter stops at the current position.
← → / h lMove the cursor; Shift moves it ten columns.
↑ ↓ / j kSelect a track. Tab moves between clips.
= - 0Zoom in, out, or fit.
a m sArm, mute, or solo a track.
bSplit the clip at the cursor.
x c vCut, copy, or paste a clip.
d delDuplicate or delete a clip.
{ }Fade in or out to the cursor.
u UUndo or redo edits.
?Open the full in-app help.

Mouse controls let you select and drag clips, set in/out markers on the ruler, toggle track controls, adjust gain or pan with the wheel, and zoom with Ctrl-wheel.

05 / Commands

Type : for more

:export [path] [mono] [16|24|32]  # mix
:stems [dir] [16|24|32]         # one file per track
:clip [path]                    # selected clip only
:import <file>                  # import at the cursor
:gain <dB>   :pan L30|C|R100    # track mix
:input 1 | 1-2   :rename <name> # track setup
:clipgain <dB>   :normalize      # clip level
:fadein <s>   :fadeout <s>      # clip fades
:latency <ms>   :goto <m:ss>    # timing
:w   :q   :q!   :wq             # save and quit

The README key reference lists every shortcut and command.

06 / Projects

Plain files you can keep

my-song/
  project.json   # tracks, clips, and gains
  audio/         # original takes and imported audio
  exports/       # rendered files

Recordings stream to WAV in audio/ and the project saves when a take finishes. Imports are copied into the project. Edits change clip references; the source audio files stay intact.

07 / Good to know

Practical details

  • Clips on a track cannot overlap. Pasting or dropping a clip overwrites what is underneath.
  • Use your audio interface's direct monitoring; asciidaw does not provide software input monitoring.
  • Latency compensation is manual. Set :latency <ms> after measuring your interface.
  • Metronome, effects, MIDI, and Windows support are not available yet.

See the repository for development notes and the complete feature reference.
